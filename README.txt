BUDGIT — REFINED PROJECT

Files:
- index.html — app structure
- script.js — app behavior and subscription logic
- sty.css — minimalist visual styling

Open index.html in a browser or use VS Code Live Server. Keep all three files together.
Subscriptions and settings are stored in this browser. Uploaded subscription logos are resized and stored locally with app data. Exchange rates are retrieved from Frankfurter (internet connection required); totals update after rates load. If rates cannot be fetched, subscriptions in another currency are temporarily excluded from converted totals rather than being converted inaccurately.
